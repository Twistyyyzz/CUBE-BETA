# CUBE-BETA
# 🎮 Уклоняйся!

Простая игра на HTML, CSS и JavaScript.

## Запуск

Открой `index.html` в браузере.

## Управление

- ← → или A/D — движение
- Space — начать игру
- На телефоне — левая/правая часть экрана

## GitHub Pages

Загрузи все файлы в репозиторий GitHub, затем открой Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.
